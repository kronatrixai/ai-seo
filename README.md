## Upload

Upload every file in this folder directly to the root of the `ai-seo` repository.

## GitHub Pages

1. Open **Settings → Pages**
2. Select **Deploy from a branch**
3. Select **main** and **/root**
4. Confirm the custom domain is `ai-seo.kronatrix.co.uk`
5. Enable **Enforce HTTPS**

## GoDaddy DNS

- Type: `CNAME`
- Host: `ai-seo`
- Points to: `kronatrixai.github.io`

## Search Console launch checklist

1. Add `https://ai-seo.kronatrix.co.uk/` as a URL-prefix property.
2. Complete verification.
3. Submit `https://ai-seo.kronatrix.co.uk/sitemap.xml`.
4. Inspect the homepage URL.
5. Request indexing.
6. Test `robots.txt`, canonical URL and mobile rendering.
7. Check the social preview and favicon.
8. Monitor impressions for `ai.seo`, `AI SEO` and related queries.
